# Data Editorial Privat

`questions.source.json` dapat dipakai sebagai arsip editorial lokal dan tidak disimpan di repositori publik. Alur build memakai bank awal yang telah dinormalisasi di `src/data/questions.demo.json`, lalu menggabungkannya dengan 100 soal tambahan untuk menghasilkan bank server 200 soal.

Gunakan `question.template.json` sebagai referensi struktur editorial. Jangan mengaktifkan soal untuk kompetisi sebelum status, sumber resmi, tanggal verifikasi, dan periode berlakunya ditelaah.
