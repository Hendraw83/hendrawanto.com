# Data Editorial Privat

`questions.source.json` tidak disimpan di repositori publik karena memuat kunci jawaban. Simpan berkas tersebut hanya di lingkungan pengembangan yang berwenang, lalu jalankan `npm run bank:build` untuk menghasilkan bank demo dan bank server.

Gunakan `question.template.json` sebagai referensi struktur editorial. Jangan mengaktifkan soal untuk kompetisi sebelum status, sumber resmi, tanggal verifikasi, dan periode berlakunya ditelaah.
