Gratis untuk Digunakan

Sistem ini terbuka untuk umum tanpa pendaftaran, maksimal 3 kali akses per pengunjung. Data yang Anda input tidak disimpan dan tidak dikirim ke server, sehingga tidak dapat dilihat pengunjung lain. Unggah template Excel, hitung, lalu unduh report PDF.
